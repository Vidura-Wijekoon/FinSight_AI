# ============================================================
# FinSight AI — pinned runtime dependencies
# Install: pip install -r requirements.txt
#
# Direct dependencies are pinned exactly. Transitive dependencies are left to
# the resolver deliberately: this project's tree includes torch, whose Linux
# builds pull CUDA packages that do not exist on Windows. A fully resolved
# lockfile generated on one platform does not install on the other, and CI and
# the container image both run Linux while development happens on Windows.
#
# The consequence, stated plainly: this gives reproducible DIRECT dependencies,
# not a reproducible full tree. Closing that gap needs per-platform lockfiles.
#
# Versions marked (tested) are the versions the passing test suite ran against.
# Versions marked (current) are not exercised by any test — see requirements.in.
#
# Edit requirements.in to change intent; edit this file to change what installs.
# ============================================================
